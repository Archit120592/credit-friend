# Photos

Drop real product photos here, then fill the paths in at the top of index.html:

- `PHOTOS.looks`  e.g. "photos/summer-hands.jpg"  (shown in "pick a look")
- `PHOTOS.charms` e.g. "photos/charms.jpg"        (charms tile)
- `PHOTOS.tools`  e.g. "photos/tools.jpg"         (tools tile)
- any product: add `img:"photos/chrome.jpg"` to its line in PRODUCTS

Anything left empty shows the drawn artwork instead.
